# Aileron — Airscape Records

Official installer downloads: [Latest release](https://github.com/iamcaptaine/Aileron-Releases/releases/latest).

Mac downloads are for Apple Silicon (AU, VST3 and AAX). Windows downloads are x64 (VST3 and AAX). Save your project and quit all DAWs before running an installer. Installation requires your approval and may request administrator authorization.

Version 0.4.11 and later includes About → Check for Updates, verified downloads, and Show Installer. Older versions require one manual update to get the checker. Checks are manual and send no license keys or session data to GitHub.

Current installers are license-enforced development/beta builds. They are unsigned; macOS is not notarized. AAX requires Pro Tools Developer until Avid/PACE signing is complete. Manufacturer Arsc replaces prototype InAu; Avid acceptance is pending. Preserve the old installer and back up sessions before upgrading older InAu installations.

This repository contains public distribution material only. Aileron source is maintained separately. Downloading an installer does not grant a software license. Contact: captain.e@airscaperecords.com.
