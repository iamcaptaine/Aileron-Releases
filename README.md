# Aileron — Airscape Records

Official installer downloads: [Latest release](https://github.com/iamcaptaine/Aileron-Releases/releases/latest).

Mac downloads are for Apple Silicon (AU, VST3 and AAX). Windows downloads are x64 (VST3 and AAX). Save your project and quit all DAWs before running an installer. Installation requires your approval and may request administrator authorization.

Version 0.4.18 offers a dismissible prompt when a startup check finds an update. Choose View Update to review and download it from About, or Not Now to continue. In About, Automatically check for updates can disable startup checks and prompts on this computer. Check for Updates remains available manually. Instances in the same loaded module share the launch result. Downloads and installation require your approval. No license keys, email, audio or session data are sent to GitHub. Earlier versions with the update checker can find this release using About > Check for Updates.

License controls enable Activate while inactive and Deactivate this device while activated. Both are disabled during license requests.

Current installers are license-enforced development/beta builds. They are unsigned; macOS is not notarized. AAX requires Pro Tools Developer until Avid/PACE signing is complete. Manufacturer Arsc replaces prototype InAu; Avid acceptance is pending. Preserve the old installer and back up sessions before upgrading older InAu installations.

This repository contains public distribution material only. Aileron source is maintained separately. Downloading an installer does not grant a software license. Contact: contact@airscaperecords.com.
